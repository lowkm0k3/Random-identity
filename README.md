# Random Identity

A lightweight Firefox extension that generates a **readable random username** and a **strong random password** in one click — perfect for throwaway signups, testing, or keeping your real identity out of the way.

## Features

- **Readable usernames** - built from adjective + noun + number (e.g. `BraveFalcon472`), so they're easy to remember and type.
- **Cryptographically secure passwords** - generated with `crypto.getRandomValues()`, not `Math.random()`.
- **Configurable** - choose password length (8–64) and toggle digits and symbols on or off.
- **One-click copy** - copy the username or password to your clipboard instantly.
- **Dark mode** - automatically follows your system theme, with a manual toggle that's remembered.
- **No tracking, no network calls** - everything runs locally in your browser.
